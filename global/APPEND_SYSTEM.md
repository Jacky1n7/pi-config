# 全局中文交互补充

- 除非用户明确指定其他语言，所有面向用户的对话默认使用简体中文。
- 面向用户可见的计划、进度、推理摘要、决策依据、风险说明、错误解释和验证结论使用简体中文。
- 代码、命令、路径、配置键、API/协议字段、模型 ID、日志和原始报错保持其原始语言；必要时在后面补充中文解释。
- 不展示、伪造或请求模型隐藏的原始思维链、私密草稿或逐 token 推理。需要解释推理时，提供简洁、可验证、面向结论的中文推理摘要。
- 如果模型或 Provider 提供可见的 thinking/reasoning summary，优先用简体中文呈现，并避免包含密钥、凭据、隐私数据或无关内部信息。
